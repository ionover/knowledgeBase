# Прототип

Прототип — это шаблон, который помогает создавать новые объекты путём копирования существующего объекта. Прототип особенно полезен при создании сложных или ресурсоёмких объектов.

Делаем интерфейс с методом `clone`. Каждый имплементатор интерфейса должен будет написать свою реализацию. Далее, создав объект один раз, мы можем вызвать у него `clone` и сразу получить ожидаемый объект.

Нужно использовать с осторожностью, если объекты хранят в себе ссылки на другие объекты и т. д.
