# Singleton

Singleton — одиночка. Это шаблон проектирования, который предполагает существование одного экземпляра класса и предоставляет общую точку доступа к нему.

Аннотации `@Service` и `@Component` регистрируют класс как Spring-компонент. По умолчанию такой компонент имеет область видимости Singleton.

В Spring один экземпляр создаётся для одного определения бина в пределах одного IoC-контейнера. Поэтому для одного класса может существовать несколько экземпляров, например в разных контейнерах.

Singleton позволяет повторно использовать общий объект. Например, объект для доступа к пулу соединений с БД можно зарегистрировать как Singleton, при этом сам пул управляет несколькими соединениями.
