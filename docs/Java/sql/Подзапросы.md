# Подзапросы

Любой SELECT внутри любой операции — это подзапрос.

Все подзапросы можно поделить на:

- **скалярный** — всегда вернёт 1 ячейку ответа (условно `2 + 2`);
- **табличный** — может вернуть множество, а может и одно; множество может быть и raw, и cells;
- **простой** — может выполниться сам по себе (условно `2 + 2`);
- **сложный** — для выполнения подзапроса нужно выполнить сам запрос.

Select может быть в любой части запроса:

```sql
SELECT dname, dprice, dprice - (SELECT AVG(dprice) FROM PD) AS dif
FROM PD
```

```sql
SELECT pnum
FROM PD
WHERE volume = (SELECT min(volume)
                FROM PD)
```

```sql
SELECT pnum
FROM PD
GROUP BY dnum
HAVING sum(volume) > (SELECT sum(volume)
                      FROM PD
                      WHERE dnum = 2)
```

# IN, ANY, SOME, ALL

```sql
WHERE name IN ('Yan', 'Doom')
```
— найдёт и Янов, и Думов (можно юзать `NOT IN`).

```sql
WHERE id = ANY (ARRAY[1, 5, 10]);
```
— по сути то же самое, что `IN`, но `ANY` можно применять с `<>`.

```sql
WHERE price < ANY (ARRAY[10, 50, 100]);
```
— по сути равноценно `price < 100`.

`SOME == ANY`, `ALL != ANY`
