# SOLID

## Для чего нужны?

Если следовать принципам разработки, то Вы получите хороший код, который в дальнейшем будет хорошо масштабироваться и поддерживаться в рабочем состоянии.

## S

Single Responsibility Principle - принцип единственной ответственности. Каждый класс должен иметь только одну зону ответственности.

## O

Open Closed Principle - принцип открытости-закрытости. Классы должны быть открыты для расширения, но закрыты для изменения.

### Пример

Нам нужно конвертировать координаты из XY в адрес и обратно. Делаем интерфейс `Converter` с методом `convert` и два имплементатора.
Когда появится необходимость конвертировать XY в YX, мы просто добавляем нового конвертёра, и всё.

## L

Liskov Substitution Principle - принцип подстановки Барбары Лисков. Должна быть возможность вместо базового (родительского) типа (класса) подставить любой его подтип (класс-наследник), при этом работа программы не должна измениться.

### Пример

Создавая наследника класса, мы делаем так, чтобы можно было на ходу подставить любого Child вместо Parent и чтобы всё работало. То есть, если у нас есть Parent "животные", то в нём не может быть метода `fly`. Потому что в классе Cat придётся либо кидать ошибку на этот метод, либо летать очень быстро и только вниз.

## I

Interface Segregation Principle - принцип разделения интерфейсов. Данный принцип обозначает, что не нужно заставлять клиента (класс) реализовывать интерфейс, который не имеет к нему отношения.

### Пример

Стараемся бить интерфейсы по S, чтобы их имплементаторам не приходилось реализовывать ненужную логику.

## D

Dependency Inversion Principle - принцип инверсии зависимостей. Модули верхнего уровня не должны зависеть от модулей нижнего уровня. И те, и другие должны зависеть от абстракции. Абстракции не должны зависеть от деталей. Детали должны зависеть от абстракций.

### Пример
В моём примере с O используются оба принципа. По сути этот принцип может говорить о том, что нельзя репозиторий звать из контроллеров, а нужно из сервиса или т.д. Если по-русски: проблемы индейцев вождя не волнуют.
