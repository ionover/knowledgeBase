# HashMap

## Для чего нужны ?

По сути просто коллекция. Ключ - значение.

## Самое важное

- Вставка за O(1) и достать тоже за O(1).
- Вообще Map это интерфейс -> hashMap - реализация.

## Информация:

Bucket -это единственный элемент массива HashMap. Он используется для хранения узлов (Nodes). Два или более узла могут
иметь один и тот -же bucket. В этом случае для связи узлов используется структура данных связанный список. Bucket -ы
различаются по ёмкости (свойство capacity).

Шаги добавления при put:

1. Вычислить хеш ключа
2. Вычислить индекс, чтобы положить в бакет
3. Сделать Node и положить в бакет, если свободный
4. Если коллизия -> смотрим equals ключей
5. Если ключи одинаковые - замена
6. Если ключи разные - храним связным списком нод

Начиная с java 8 и с размера связного списка более 10? строиться дерево

## Грабли

При работе в формате stream мы не можем позвать его у мапы. Но мы можем позвать entrySet через который можно позвать
стрим. Тоже самое и с forEach.
Не гаранитрует порядок обхода

## Дополнения

- Потокобезопасность:
  HashMap не потокобезопасный. Для многопоточности лучше использовать ConcurrentHashMap.

- capacity, loadFactor, threshold:
  capacity - количество бакетов.
  loadFactor - коэффициент загрузки (по умолчанию 0.75).
  threshold = capacity * loadFactor.
  Когда количество элементов превышает threshold, происходит resize.
