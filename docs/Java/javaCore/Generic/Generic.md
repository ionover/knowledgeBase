# Generic

## Для чего нужны?

`Generic` -> обобщенные типы. Пример: `List<T>`.
Нужны, чтобы пользоваться полиморфизмом, при этом оставляя возможность пользоваться внутренними методами.
Type Inference

## Самое важное

Постоянно в коллекциях и стримах.

## Информация

Массивы в Java ковариантны. И это плохо.

```java
String[] strings = new String[]{"a", "b", "c"};
Object[] arr = strings;
```

Теперь можно в `arr` вносить числа или POJO, и в рантайме это убьет программу.

«Дженерики» инвариантны, и

```java
List<Integer> ints = Arrays.asList(1, 2, 3);
List<Number> nums = ints;
```

Вызовет ошибку компиляции.

### Wildcards (Integer extends Number)

- `? extends Number` -> ставит левую границу (Number и его наследников).
- `? super Integer` -> ставит правую границу (Integer и его родителей).

Если контейнер объявлен с wildcard `? extends`, то можно только читать значения. В список нельзя ничего добавить, кроме
`null`. Для того чтобы добавить объект в список, нам нужен другой тип wildcard — `? super`.

Можно сделать `Collection<?>`, что равно `<? extends Object>`, а значит, мы можем только читать.

Есть Raw (опустили тип) типы, но в современной Java нет смысла в этом.

## Грабли

При компиляции типы стираются и везде получается условно `Object` (`Type Erasure`). Поэтому нельзя делать перегрузки
методов, например через коллекции.

`<? extends Object>` не меняет `Type Erasure`: и `List<T>`, и `List<? extends Object>` после стирания дают `List`.

В процессе могут добавляться бридж-методы.

При стирании можно потерять часть информации об объекте, объекты, которые не теряют информацию (например, примитивы),
это Reifiable-типы.

Exception не могут быть параметризованными (написано однажды, работает всегда - больно бьет). Throwable и его подтипы не
могут быть параметризованы, потому что try-catch проверяет типы.

Heap Pollution - загрязнение кучи.

## Дополнения

Можно использовать `instanceof`, бегая по коллекции, чтобы определять классы объектов.

Можно сделать `List<Parent>` и `add(new Child)`, но наоборот нельзя (полиморфизм работает).
