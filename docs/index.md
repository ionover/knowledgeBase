# Личная база знаний

Добро пожаловать в базу знаний.

## Как работать

1. Запусти локальный редактор.
2. Создавай и редактируй статьи в структуре папок (например `Java/Core/Spring.md`).
3. Проверь сайт локально через MkDocs.
4. Сделай `git push`, и GitHub Actions опубликует изменения в GitHub Pages.
