# Markdown: база

## Заголовки

```md
# Заголовок 1
## Заголовок 2
### Заголовок 3
```

## Акценты в тексте

```md
*курсив*
**жирный**
***жирный курсив***
~~зачеркнутый~~
```

## Код

```md
`код в строке`
```

````md
```java
System.out.println("Hello");
```
````

## Списки

```md
- Пункт
- Еще пункт
  - Вложенный пункт
```

```md
1. Первый
2. Второй
3. Третий
```
